## 🍂 ATO IV — OUTONO

<div align="center">

</div>

### 🔐 Sealed Secrets → External Secrets Operator

O gerenciamento de segredos precisava sair de uma lógica distribuída e ganhar uma fonte de verdade mais apropriada para o ambiente.

Liderei a migração de **Sealed Secrets** para **External Secrets Operator (ESO)**, usando o **AWS Secrets Manager** como backend e levando o padrão para **dev, QA e HML**.

- Segredos desacoplados dos manifestos versionados.
- Gestão centralizada e mais flexível de credenciais.
- Fluxo mais alinhado com GitOps e com a evolução dos ambientes.
- Uma base mais limpa para rotação e manutenção dos acessos.

### 🛠️ Gerenciamento de nodes Cassandra

Em ambientes de QA para baixo, a manutenção de Cassandra não pode depender de lembrete, planilha ou intervenção repetitiva.

Por isso, lidero uma ferramenta própria para gerenciar nodes Cassandra, com **agendamento automatizado de repairs**, acompanhamento dos clusters e o **Cassandra Reaper** operando por trás da aplicação.

- Rotinas recorrentes tratadas como processo, não como tarefa manual.
- Mais visibilidade sobre a saúde dos clusters.
- Operação mais previsível para os ambientes não produtivos.
- Menos atrito para quem precisa cuidar da plataforma todos os dias.
